## New features
- **Observer — stand observability.** A bundle that names the `observer` image now brings the service up together with its own PostgreSQL: log and OTLP telemetry intake, a built-in UI on port 17016, and monitoring of the stand's RabbitMQ, PostgreSQL and ZooKeeper. The `observer` flag in `namespace.yml` is gone — whether a stand has observability is decided by the release it runs, not by the stand's own file, and the old key is simply ignored. Its database is a fully managed dependency: its own version pin, its own volume generation, `citeck deps upgrade observer-postgres` and `citeck deps rollback observer-postgres`.
- **Apps arriving with a new bundle for the first time no longer start by themselves** when the workspace template lists them under `detachedApps`. Such an app shows up stopped, with a Play button; `citeck start <app>` turns it on for good. Apps you were already running are left alone — an existing container counts as proof — and when Docker or the workspace repository cannot be asked, the decision is postponed to the next load instead of being guessed.
- **Additional databases are declared in the workspace config.** The new `databases:` section (id, image, user, port, memory limit, server settings, `requiredBy`) means another PostgreSQL cluster no longer needs a new launcher release, and it gets everything the main database has: a version pin, the volume generation counter, major-version migration and rollback.
- **Dependency upgrade reports.** Every `citeck deps upgrade` and `citeck deps rollback`, and every refused pre-check, writes a plain-text report into `logs/reports/`: what held the upgrade back, which step it stopped at, and the logs of the temporary containers, captured BEFORE the rollback removed them. The reports are included in the system information archive (`citeck dump-system-info`), so "it won't update" is now an answerable question.

## Changes
- The launcher no longer detaches apps on its own. A companion of a stopped app (`qdrant` for `rag`, `stt-sidecar` for `ai`) now starts with the namespace like any other app — to keep the stand from paying for it, stop it with `citeck stop <app>` or list it in the template's `detachedApps`.

## Fixes
- The system information archive no longer masks image versions. A value the same container publishes in a non-secret field — the database user `postgres`, for example — is no longer treated as a password; before this the whole archive could come out with `***REDACTED***` in place of image tags.
