## Correções
- **Segurança: o proxy não entrega mais uma identidade a uma requisição não autenticada.** Com autenticação via Keycloak, seu script de acesso comparava as exceções de serviço com o URI bruto da requisição, de modo que um marcador infiltrado pela query string (`?probe=/healthcheck/`), por um segmento no meio do caminho ou atrás de um `../` codificado fazia com que o cabeçalho confiável `X-ECOS-User` fosse definido em uma requisição roteada para qualquer endpoint do gateway. Agora a comparação é feita com o caminho que o nginx realmente roteou, e as exceções de `/healthcheck/`, `/rabbitmq`, `/cadvisor/` e dos exportadores de métricas foram removidas — essas locations têm autenticação própria e nunca executaram este script.
- A atualização recria o contêiner do proxy uma vez, para que o script corrigido entre em vigor.
