## 新功能
- **自动更新现已支持 macOS 和 Windows**，不再仅限于 Linux。启动器会自行下载新版本、校验签名并完成安装。

## 修复
- **中断的更新不会再让启动器无法启动。** 已下载但从未校验的更新（应用在此期间被关闭或崩溃），现在会在下次启动时做健康检查，若无法启动则自动回滚。
- **Alfresco 和 Solr 不会再收到其 Java 8 无法识别的 JVM 参数。** 无法识别的参数不会被忽略：JVM 会直接拒绝启动。
- **Alfresco 和 Solr 依据容器上限计算内存。** 此前 Solr 的堆大小与自身容器上限相同，最终只会被内核杀掉；Alfresco 则完全没有上限。现在 Solr 的上限为 2560 MB，Alfresco 为 8 GB。
- **服务不再在启动时占满整个堆。** `heapSize` 现在只设置上限，因此启动大型命名空间会按实际需要占用内存。

## 改进
- 守护进程日志不再在每次重新加载时为每个服务重复输出 JVM 内存计算结果。
- 使用 Go 1.26.6 构建，其中包含标准库的安全修复。

## 升级
- 更新后首次启动时，Java 容器会重建一次。
