## Новые возможности
- **Автообновление работает на macOS и Windows**, а не только на Linux. Лаунчер сам скачивает новую версию, проверяет её подпись и устанавливает.

## Исправления
- **Прерванное обновление больше не оставляет лаунчер неспособным запуститься.** Обновление, которое скачалось, но не было проверено — приложение закрыли или оно упало между шагами, — теперь проверяется при следующем запуске и автоматически откатывается, если не поднимается.
- **Alfresco и Solr больше не получают параметры JVM, которых не понимает их Java 8.** Неизвестный параметр не игнорируется: JVM просто отказывается стартовать.
- **Alfresco и Solr считают память от лимита контейнера.** Раньше heap у Solr был равен размеру его же контейнера — это заканчивается тем, что процесс убивает ядро, — а у Alfresco лимита не было вовсе. Теперь лимит Solr равен 2560 МБ, у Alfresco — 8 ГБ.
- **Сервисы больше не занимают весь heap при старте.** `heapSize` задаёт только максимум, поэтому запуск большого стенда забирает память по мере надобности.

## Улучшения
- В логе демона больше не повторяется расчёт памяти JVM для каждого сервиса при каждой перезагрузке.
- Сборка на Go 1.26.6 — с исправлениями безопасности в стандартной библиотеке.

## Обновление
- При первом запуске после обновления Java-контейнеры один раз пересоздаются.
