## 新機能
- **自動更新が macOS と Windows でも動作するようになりました。** Linux 限定ではなくなり、ランチャー自身が新しいバージョンをダウンロードし、署名を検証してインストールします。

## 修正
- **中断された更新でランチャーが起動できなくなることはなくなりました。** ダウンロードされたものの検証されなかった更新（途中でアプリを閉じた、あるいはクラッシュした場合）は、次回起動時にヘルスチェックされ、起動しなければ自動的にロールバックされます。
- **Alfresco と Solr に、その Java 8 が解釈できない JVM オプションを渡さなくなりました。** 未知のオプションは無視されず、JVM がそもそも起動しません。
- **Alfresco と Solr はコンテナの上限からメモリを算出します。** これまで Solr のヒープはコンテナ自体と同じ大きさで、最終的にカーネルに強制終了されていました。Alfresco には上限がまったくありませんでした。現在の上限は Solr が 2560 MB、Alfresco が 8 GB です。
- **サービスは起動時にヒープ全体を確保しなくなりました。** `heapSize` は最大値のみを指定するため、大きなネームスペースの起動でも必要に応じてメモリを使います。

## 改善
- デーモンのログが、リロードのたびに各サービスの JVM メモリ計算を繰り返し出力しなくなりました。
- Go 1.26.6 でビルドしました。標準ライブラリのセキュリティ修正が含まれます。

## アップグレード
- 更新後の初回起動時に、Java コンテナが一度だけ再作成されます。
