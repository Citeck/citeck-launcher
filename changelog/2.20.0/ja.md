## 新機能

- Web アプリのコンパニオン設定（`webapps[].companions`）: オプションの LLM ゲートウェイなどのコンパニオンサービスが環境に存在する場合にのみ、ワークスペースから Web アプリへ環境変数と起動依存関係を適用できるようになりました。名前空間側の上書き設定が優先されます。
- 追加サービス向けメイン PostgreSQL データベース（`additionalApps[].postgresDatabases`）: カスタムサービスが環境のメイン PostgreSQL クラスタにデータベースを作成でき、機能の切り替え時に PostgreSQL を再作成することなく、マイグレーション、スナップショット、pgAdmin に自動で含まれます。
- カスタムサイドバーリンクの多言語ツールチップ（`links[].descriptions`）: ワークスペースのリンクで言語ごとのツールチップ（後方互換フォールバック付き）に対応し、UI の言語切り替え時に即座に更新されるようになりました。
- サイドバーに LiteLLM アイコンを追加し、Mailpit アイコンを更新しました。
