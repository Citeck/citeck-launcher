## Новые возможности

- Настройки сервисов-компаньонов для веб-приложений (`webapps[].companions`): workspace может передавать веб-приложениям переменные окружения и зависимости запуска только пока нужный сервис-компаньон (например, опциональный LLM-шлюз) присутствует на стенде, с сохранением приоритета настроек `namespace.yml`.
- Базы данных в основном PostgreSQL стенда для дополнительных сервисов (`additionalApps[].postgresDatabases`): пользовательские сервисы могут запрашивать базы в основном кластере PostgreSQL стенда — они автоматически участвуют в миграциях, снапшотах и отображаются в pgAdmin без пересоздания PostgreSQL при переключении функций.
- Локализованные подсказки для пользовательских ссылок (`links[].descriptions`): ссылки workspace теперь поддерживают переводы подсказок по языкам с обратной совместимостью, а интерфейс сразу обновляет их при переключении языка.
- Добавлена иконка LiteLLM для боковой панели и обновлён логотип Mailpit.
