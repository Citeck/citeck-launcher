## 新機能
- 名前空間の作成時に DB または S3 を選択できます。S3 の利用可否は選択したバンドルとエディションに従います。
- エージェント API とデーモンを起動しない検出コマンドで、Launcher が対応する操作を確認できます。
- Git 更新の失敗時にキャッシュの使用、再試行、リポジトリごとのトークン選択が可能になり、最後に同期が成功した時刻を表示します。
- 更新とスナップショットのダウンロードで受信バイト数を表示し、中断した転送を自動で再開します。

## 修正
- バイトの受信が続く限り、転送全体の時間制限なしでダウンロードを継続します。
- 通常の S3 初期化ではバナーを表示せず、設定エラーと接続エラーは引き続き表示します。
- Mailpit のホストポートは SMTP が 17011、ウェブ画面が 17012 です。
- Git 診断でリポジトリ URL に含まれる認証情報を隠します。
