## Новые возможности
- При создании пространства можно выбрать хранение контента в DB или S3; доступность S3 зависит от выбранного бандла и редакции.
- Агентский API и команды обнаружения без запуска демона описывают поддерживаемые операции Launcher.
- При ошибке обновления Git можно использовать кэш, повторить попытку или выбрать токен для конкретного репозитория; показано время последней успешной синхронизации.
- Загрузка обновлений и снимков показывает полученные байты и автоматически возобновляется после обрыва.

## Исправления
- Активная загрузка продолжается, пока поступают байты, без ограничения общей длительности.
- Обычная инициализация S3 больше не показывает баннер; ошибки настройки и подключения остаются видимыми.
- Mailpit использует порты хоста 17011 для SMTP и 17012 для веб-интерфейса.
- Диагностика Git скрывает учётные данные в URL репозиториев.
