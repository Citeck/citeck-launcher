## 新功能
- 创建命名空间时可选择 DB 或 S3 内容存储；S3 是否可用取决于所选 bundle 和版本。
- 代理 API 和无需启动守护进程的发现命令描述 Launcher 支持的操作。
- Git 更新失败时可使用缓存、重试或为特定仓库选择令牌，并显示上次成功同步的时间。
- 更新和快照下载显示已接收字节，并自动续传中断的下载。

## 修复
- 只要持续接收字节，下载就会继续，不再限制总传输时间。
- 正常的 S3 初始化不再显示横幅；配置和连接错误仍然可见。
- Mailpit 使用主机端口 17011 提供 SMTP，端口 17012 提供网页界面。
- Git 诊断会隐藏仓库 URL 中的凭据。
