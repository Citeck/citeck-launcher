## Изменения
- **Порты, опубликованные без адреса, теперь слушают только 127.0.0.1.** Раньше такой порт был открыт на всех интерфейсах, а Docker обходит файрвол хоста. На всех интерфейсах публикуется только прокси (в серверном режиме всегда, на десктопе — когда хост namespace не локальный). Чтобы открыть порт в сеть, укажите адрес сами: `'*:15432:5432'` — все интерфейсы, или конкретный адрес. Запущенный контейнер сохраняет старую привязку, пока его не пересоздадут.
- Правка `ports` прокси, сохранённая прежней версией, не содержит адреса, поэтому теперь тоже означает 127.0.0.1 — проверьте её через `citeck edit proxy`.
- Ссылки на RabbitMQ, Mailpit и PgAdmin открываются на этой машине (127.0.0.1 / localhost).

## Исправления
- `citeck edit` принимает порт с адресом (`127.0.0.1:15432:5432`); раньше из-за такого порта приложение не запускалось. Порт, который лончер не может разобрать, отклоняется до сохранения.
- Слишком большая правка или описание без образа отклоняются, а не сохраняются обрезанными.
- На кластерах PostgreSQL, созданных старым образом, снова можно создавать базы (после обновления glibc их блокировало несовпадение версии collation). Контейнер postgres пересоздаётся один раз.
- Безопасность: прокси больше не пропускает анонимные запросы к ресурсам Alfresco и Share (`/alfresco/…`, `/share/res/…`) от имени пользователя guest. Контейнер прокси пересоздаётся один раз.
