## 新機能
- **設定ページ。** 歯車アイコンから本格的な設定ページを開けるようになりました。ワークスペースの Git リポジトリ設定と、プライベート Docker レジストリの認証情報をまとめて扱えます。これまではホバーメニューかエラーダイアログからしか到達できませんでした。

## 修正
- **macOS:「citeck-launcher is damaged and can't be opened」。** ダウンロードしたビルドに署名がなく、Gatekeeper がこの紛らわしいメッセージで起動を拒否し、回避手段もありませんでした。アプリバンドルに再び署名するようにしたため、初回起動では通常の「開発元が未確認」の警告が出るだけになります。右クリック →「開く」で一度起動してください。
- **1.x からのアップグレードでワークスペースが失われなくなりました。** 旧データベースを読み取れない場合、ランチャーは黙って空のワークスペースに置き換えていました。リポジトリの URL とブランチを既存のクローンから復元するようになり、すべてを移行できなかった場合はその旨を通知します。新規インストールのように見えることはもうありません。
- **ネットワークの瞬断でバンドルリポジトリが入れ替わらなくなりました。** Git プル中の短いタイムアウトによって、あるリポジトリが別のリポジトリの内容で置き換わることがありました。一時的なネットワークエラーでは既存のコピーを保持し、別のリポジトリを入れてしまう再クローンは中止します。
- **レジストリの認証情報を修正できます。** 最初に誤ったシークレットを選ぶと元に戻せませんでした。バインドは設定に一覧表示され、再割り当てや削除ができます。他のホストの認証情報は有効に見せず、警告を表示します。
- **不明なバンドルリポジトリのエラーが明確になりました。** Citeck の既定ワークスペースを黙って使う代わりに、リポジトリ名、宣言済みの ID、修正すべき場所を示します。
- **歯車アイコンが消えなくなりました。** ネームスペースを開いていない状態でクリックすると、ようこそ画面に戻ってアイコンごと消えていました。
