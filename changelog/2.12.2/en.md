## Fixes
- **Fixes a broken launcher after updating from 2.12.0 to 2.12.1.** An update replaces the daemon only — the desktop app around it stays the version you installed — and 2.12.1's daemon answered a request for the window with a JSON refusal while it was still starting, which the older app put on screen and left there. A starting daemon now shows a loading indicator instead and the window comes back on its own a moment later. If you are already on a white screen with JSON on it, reinstall the launcher (or delete the `updates` folder in the launcher's data directory) — this release prevents it from happening again.
