## 新機能
- **コンテンツの保存先：データベースまたは S3。** SeaweedFS を含む Enterprise バンドル（最初は 2026.3-RC6）のネームスペースでは、アップロードされたファイルを PostgreSQL データベースではなく S3 に保存できるようになりました。ネームスペースの作成・編集ダイアログの **「コンテンツの保存先」** で **S3 (SeaweedFS)** を選択してください。デフォルトは引き続き **「データベース」** で、既存のネームスペースのコンテンツはデータベースに保存されたままです。その他の Enterprise バンドルでは、この項目は表示されますが、S3 は理由とともに選択不可として示されます。
- S3 を選ぶと、ランチャーは SeaweedFS をネームスペースと一緒に起動し、プラットフォームが立ち上がった時点で ecos-content を SeaweedFS に自動的に接続します。ECOS 側での設定は不要です。管理者が ECOS で別のストレージをすでにデフォルトにしている場合、ランチャーはその選択を変更しません。デスクトップでは、進行状況がダッシュボードのバナーに表示され、接続に失敗した場合は **「再試行」** でやり直せます。ランチャー自身も再試行します。
- ネームスペースは後からデータベースから S3 に切り替えられますが、元に戻すことはできません。切り替え前にアップロードされたファイルはデータベースに残ります。
- デスクトップでは、コンテンツを S3 に保存しているネームスペースで SeaweedFS を停止するときに確認を求められ、`citeck stop seaweedfs` は警告を表示します。SeaweedFS が停止している間は、ファイルのアップロードもダウンロードもできません。
- ネームスペースの S3 キーが新しくなると、ランチャーは ECOS 側のコピーも更新します。たとえば、スナップショットを新しいネームスペースに復元したときや、デスクトップでマスターパスワードをリセットしたときです。
- サーバーモード：`citeck install` は、選んだリリースが S3 に対応していれば、リリースの選択後にコンテンツの保存先を尋ねます。`citeck setup content-storage` で既存のネームスペースを S3 に切り替えられ（daemon が実行中である必要があります）、コンテンツを S3 に保存しているネームスペースでは `citeck status` に `Content storage:` の行が表示されます。
- デスクトップでは、バンドルに SeaweedFS を含むネームスペースのサイドバーの **「アプリ」** に **SeaweedFS** へのリンクが表示され、SeaweedFS の管理画面を開けます（ユーザー名 `admin`、パスワード `admin`）。SeaweedFS が起動していない間（コンテンツをデータベースに保存している場合など）は、リンクはグレー表示になります。
- `citeck setup admin-password` は、再作成されるまで古いパスワードを受け付け続けるアプリ（SeaweedFS など）を表示するようになりました。それらは `citeck reload` で再作成されます。
- ワークスペース作成者向け：`secrets:` に自動生成のシークレットを記述できるようになりました。`id: <id>` + `generated: {length: 40}`（`length:` は省略可、16〜128、デフォルト 40）と書くと、ネームスペースごとに個別のランダムな値が一度だけ生成され、以後その値が保持されます。 Launcher 2.16 以降が必要です。
- ワークスペース作成者向け：`category: Apps` または `Resources` の `links:` エントリは、下部に独自の見出しを作らず、サイドバーの組み込みグループ（「アプリ」または「リソース」）に加わるようになりました。

## スナップショット
- `--include-secrets` を指定すると、認証キーや管理者・サービスアカウントのパスワードを含む名前空間のシークレットを別のプロファイルに移せます。既定では含まれません。このオプションを使うとアーカイブに平文で保存されるため、厳重に管理してください。
- インポートでは依存サービスのバージョンとボリューム世代をシークレットと一緒に復元します。中断後は再インポートが成功するまで起動できません。CLI はインポート失敗後に名前空間を再起動しなくなりました。ボリュームの内容はメタデータのトランザクション対象外です。
- 既存データを変更する前にアーカイブを検証します。外部 S3 のオブジェクトと名前空間の設定は含まれません。
