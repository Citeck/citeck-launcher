## 新功能

- 本地 AI 代理可通过 MCP 查看状态和日志；Developer 角色还可管理应用、修改运行参数和 Spring 配置，以及收集 JVM 诊断信息。
- 在桌面应用设置中管理代理访问：批准 OAuth 登录或手动创建令牌，选择 Observer 或 Developer 角色，设置有效期并撤销访问。MCP 默认关闭，启用后仅监听回环地址。
- 可在应用配置编辑器中按 CPU 核数设置各应用的 CPU 限制，支持小数。

## 修复

- 重新加载配置时会报告生成的配置文件写入失败，不再使用未保存的文件继续执行。
- 当当前配置文件不可用且无法重新应用已保存的修改时，不再悄然将文件内容替换为空。
- 编辑包含多个 YAML 文档的配置文件时会保留所有文档。
- JVM 诊断命令一旦可能已发送到 JVM，就不再自动重复执行。
