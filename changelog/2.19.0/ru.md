## Новые возможности

- Локальные AI-агенты могут подключаться по MCP для просмотра состояния и логов. Роль Developer также позволяет управлять приложениями, менять параметры запуска и конфигурацию Spring, собирать диагностику JVM.
- Управление доступом агентов в настройках десктопного приложения: подтверждение входа по OAuth или создание токенов вручную, выбор роли Observer или Developer, срока действия и отзыв доступа. MCP по умолчанию выключен; после включения доступен только через loopback.
- В редакторе конфигурации приложения можно задать лимит CPU в ядрах, в том числе дробный.
