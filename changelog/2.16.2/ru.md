## Исправления
- При смене версии Launcher репозиторий workspace обновляется без ожидания таймера pull. Версия успешного обновления запоминается для каждого клона; повторные desktop-запуски сохраняют обычный таймер, серверные — ручное обновление. Учитываются режим offline, импортированный workspace и пользовательский Skip. При ошибке остаётся кэш, а попытку можно повторить без ожидания таймера.
